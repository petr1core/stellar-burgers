# Тесты Cypress для Stellar Burgers

## Описание

Набор тестов Cypress для проверки функциональности приложения Stellar Burgers. Тесты покрывают все основные сценарии использования приложения.

## Структура тестов

### 0. `smoke.cy.ts` - Smoke тест
- Загрузка главной страницы и ингредиентов
- Проверка кнопок добавления ингредиентов
- Базовая навигация между страницами
- **Рекомендуется запускать первым для проверки работоспособности**

### 1. `constructor.cy.ts` - Конструктор бургера
- Добавление ингредиентов в конструктор через кнопки "Добавить"
- Открытие и закрытие модальных окон с описанием ингредиентов
- Проверка корректности данных в модальных окнах
- Создание заказов
- Очистка конструктора после создания заказа
- Валидация кнопки оформления заказа

### 2. `auth.cy.ts` - Авторизация пользователя
- Вход в систему
- Регистрация нового пользователя
- Выход из системы
- Обновление токенов
- Перенаправление неавторизованных пользователей

### 3. `navigation.cy.ts` - Навигация по приложению
- Переходы между страницами
- Работа с навигационным меню
- Проверка активных ссылок
- Навигация браузера (кнопка "Назад")

### 4. `feed.cy.ts` - Лента заказов
- Отображение заголовка и статистики
- Отображение списка заказов
- Работа с модальными окнами

### 5. `profile.cy.ts` - Профиль пользователя
- Отображение данных профиля
- Редактирование профиля
- Валидация форм
- Сохранение изменений
- Выход из системы

### 6. `profile-orders.cy.ts` - История заказов пользователя
- Отображение истории заказов
- Навигация к профилю

### 7. `forms.cy.ts` - Формы авторизации и регистрации
- Валидация форм
- Обработка ошибок
- Успешные операции
- Переходы между формами

## Запуск тестов

### Предварительные требования
1. Установленный Node.js
2. Запущенное приложение на `http://localhost:5000`

### Установка зависимостей
```bash
npm install
```

### Запуск smoke теста (рекомендуется первым)
```bash
npx cypress run --spec "cypress/e2e/smoke.cy.ts"
```

### Запуск всех тестов
```bash
npx cypress run
```

### Запуск тестов в интерактивном режиме
```bash
npx cypress open
```

### Запуск конкретного теста
```bash
npx cypress run --spec "cypress/e2e/constructor.cy.ts"
```

## Конфигурация

### `cypress.config.ts`
- Base URL: `http://localhost:5000`
- Viewport: 1280x720
- Timeout: 15 секунд
- Retries: 2 для run mode, 1 для open mode

### Фикстуры
- `ingredients.json` - данные ингредиентов
- `order.json` - данные заказов
- `user.json` - данные пользователя
- `profile.json` - данные профиля

## Перехват API запросов

Все тесты используют `cy.intercept()` для подмены запросов к бэкенду:

```typescript
cy.intercept('GET', 'https://norma.nomoreparties.space/api/ingredients', { 
  fixture: 'ingredients.json' 
}).as('getIngredients');
```

## Авторизация в тестах

Для тестов, требующих авторизации, используются фейковые токены:

```typescript
cy.setCookie('accessToken', 'test-access-token');
cy.setCookie('refreshToken', 'test-refresh-token');
```

После каждого теста токены очищаются:

```typescript
afterEach(() => {
  cy.clearCookies();
  cy.clearLocalStorage();
});
```

## Селекторы элементов

Тесты используют следующие селекторы для поиска элементов:

### Конструктор
- `[data-testid="ingredient-bun"]` - ингредиенты-булки
- `[data-testid="ingredient-main"]` - ингредиенты-начинки
- `[data-testid="ingredient-sauce"]` - ингредиенты-соусы
- `[data-testid="add-button-bun"]` - кнопки добавления булок
- `[data-testid="add-button-main"]` - кнопки добавления начинок
- `[data-testid="constructor-bun-top"]` - верхняя булка в конструкторе
- `[data-testid="constructor-bun-bottom"]` - нижняя булка в конструкторе
- `[data-testid="constructor-ingredients-area"]` - область начинок
- `[data-testid="order-button"]` - кнопка оформления заказа
- `[data-testid="total-price"]` - общая цена заказа

### Модальные окна
- `[data-testid="ingredient-details-modal"]` - модальное окно ингредиента
- `[data-testid="modal-close-button"]` - кнопка закрытия модального окна
- `[data-testid="modal-overlay"]` - оверлей модального окна

### Формы
- `input[type="email"]` - поле ввода email
- `input[type="password"]` - поле ввода пароля
- `input[name="name"]` - поле ввода имени
- `cy.contains('Войти')` - кнопка входа
- `cy.contains('Зарегистрироваться')` - кнопка регистрации

### Навигация
- `cy.contains('Конструктор')` - ссылка на конструктор
- `cy.contains('Лента заказов')` - ссылка на ленту заказов
- `cy.contains('Личный кабинет')` - ссылка на профиль
- `cy.contains('Профиль')` - заголовок профиля

## Обработка ошибок

Тесты включают проверки:
- Ошибок валидации форм
- Ошибок API запросов
- Сообщений об ошибках
- Состояний загрузки

## Стабильность тестов

Для повышения стабильности тестов:
- Используются `cy.wait()` для ожидания API ответов
- Добавлены retries в конфигурации
- Очистка состояния между тестами
- Обработка асинхронных операций

## Важные замечания

- Тесты адаптированы под реальную структуру DOM приложения
- Используются существующие `data-testid` атрибуты где возможно
- Для остальных элементов используются CSS селекторы и текстовые селекторы
- Все тесты проходят проверку на реальном приложении
