# Jest тесты для Stellar Burgers

## Описание

Unit тесты для проверки Redux логики и компонентов приложения.

## Быстрый старт

```bash
# Запуск всех тестов
npm test

# Запуск с покрытием
npm test -- --coverage

# Режим watch
npm test -- --watch
```

## Структура тестов

### Redux тесты
- `store.test.ts` - rootReducer и начальное состояние
- `*/slice.test.ts` - редьюсеры и синхронные экшены
- `*/order.test.ts` - асинхронные экшены (pending/fulfilled/rejected)

### Компонентные тесты  
- `login.test.tsx` - тест страницы логина

## Что тестируется

### Redux логика
- Корректная инициализация rootReducer
- Синхронные экшены (добавление/удаление ингредиентов)
- Асинхронные экшены (все фазы: pending → fulfilled/rejected)
- Состояния загрузки и ошибок

### React компоненты
- Рендеринг компонентов
- Обработка пользовательского ввода
- Валидация форм
